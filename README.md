# SA-MP Web Panel

موقع ويب للاتصال بقاعدة بيانات SA-MP وعرض معلومات اللاعبين مثل الرصيد.

## المتطلبات

- خادم ويب (Apache/Nginx)
- PHP 7.4 أو أحدث
- MySQL/MariaDB
- قاعدة بيانات SA-MP

## التثبيت

1. قم بإنشاء قاعدة بيانات جديدة باسم `samp_server`
2. استورد جدول اللاعبين من سيرفر SA-MP الخاص بك
3. عدل إعدادات قاعدة البيانات في ملف `database.php`:

```php
$host = 'localhost';
$username = 'root';
$password = '';
$database = 'samp_server';
```

## هيكل قاعدة البيانات

يجب أن يحتوي جدول `players` على الأعمدة التالية:
- `id` - معرف اللاعب
- `username` - اسم المستخدم
- `password` - كلمة المرور (مشفرة بـ bcrypt)
- `money` - رصيد اللاعب

## الاستخدام

1. افتح المتصفح واذهب إلى `http://localhost/موقع/login.php`
2. أدخل اسم المستخدم وكلمة المرور الخاصة بحساب SA-MP
3. ستظهر لك لوحة التحكم مع رصيدك الحالي

## الأمان

- كلمات المرور مشفرة باستخدام bcrypt
- استخدام Prepared Statements لمنع حقن SQL
- جلسات آمنة للمستخدمين

## الملفات

- `database.php` - ملف الاتصال بقاعدة البيانات
- `login.php` - صفحة تسجيل الدخول
- `dashboard.php` - لوحة التحكم وعرض الرصيد
- `logout.php` - صفحة تسجيل الخروج
- `style.css` - ملف التنسيق
